Artifact: CS-360 Event Tracking App

This artifact demonstrates my ability to design and improve a mobile application through structured enhancements in usability, validation, and functionality.

Artifact Description

The chosen artifact for this milestone is the CS‑360 Event Tracking Mobile Application. This application was initially created during the CS‑360 Mobile Architecture and Programming course. Its main purpose is to enable users to log in and manage their personal events by creating, viewing, editing, and deleting event entries. The application is built using Android Studio and utilizes a SQLite database for persistent data storage.

The app features several components, including a login interface, an event list display that employs a RecyclerView, and dialogs for adding and editing events. These components collaborate to deliver a comprehensive mobile application that showcases full-stack mobile development capabilities.

Justification for Inclusion

This artifact was chosen for my ePortfolio as it showcases my growth in software engineering by creating a fully functional mobile application from scratch. It emphasizes my capability to merge user interface design, database management, and application logic into a unified solution.

Moreover, this project lays a solid groundwork for further improvements. By reviewing and refining the artifact, I was able to pinpoint design issues, performance shortcomings, and areas for usability enhancement.

Enhancements and Skills Demonstrated

Several improvements were made to enhance the application's design, usability, and performance. I revised the login functionality to prevent unintended user creation and implemented clear authentication feedback. I also added input validation to ensure required event fields are completed before saving, improving data integrity.

Additionally, I improved data organization by adding sorting functionality and optimized the user interface by reducing unnecessary full list refreshes. These changes improved performance and demonstrated better software design practices.
