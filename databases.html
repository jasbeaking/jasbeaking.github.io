Artifact: CS-360 Event Tracking App

This artifact demonstrates my ability to design and improve a mobile application through structured enhancements in usability, validation, and functionality.

Artifact Description

The chosen artifact for this milestone is the CS‑360 Event Tracking Mobile Application. This application was initially created during the CS‑360 Mobile Architecture and Programming course. Its main purpose is to enable users to log in and manage their personal events by creating, viewing, editing, and deleting event entries. The application is built using Android Studio and utilizes a SQLite database for persistent data storage.

The app features several components, including a login interface, an event list display that employs a RecyclerView, and dialogs for adding and editing events. These components collaborate to deliver a comprehensive mobile application that showcases full-stack mobile development capabilities.

Enhancements and Skills Demonstrated

Several database-related enhancements were implemented to improve the organization, reliability, and efficiency of the application.

First, I improved the way events are retrieved from the database by modifying the query to include sorting using an ORDER BY clause. This ensures that events are displayed in chronological order based on date and time. Organizing data at the database level improves efficiency and reduces the need for additional processing within the application. It also allows the data to be returned in a more structured and user-friendly format.

Second, I improved data integrity by implementing input validation before inserting or updating records in the database. This prevents incomplete or invalid data, such as empty event names or missing dates and times, from being stored. As a result, the data remains consistent and reliable, which helps avoid errors in how information is displayed and managed throughout the application.

Third, I improved the login functionality by separating user authentication from automatic registration behavior. Previously, invalid login attempts could result in unintended user creation. By correcting this, the database is no longer populated with unintended or duplicate records, which improves overall data accuracy.

Additionally, I enhanced the database structure by enforcing uniqueness on usernames. This prevents duplicate user accounts from being created and ensures that each user is uniquely identified within the system. This change improves data consistency and reduces the likelihood of conflicts when managing user data.

Finally, I improved how data changes are reflected in the application by reducing unnecessary full data reloads when events are added or removed. While this is primarily a performance improvement, it also reduces repeated database calls and ensures that only the necessary data is updated. This contributes to more efficient data handling and better overall system performance.

These enhancements demonstrate my understanding of database concepts such as query optimization, data validation, constraint enforcement, and efficient data handling. Together, they contribute to building a more reliable and well-structured application.
