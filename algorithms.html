Artifact Description

The chosen artifact for this milestone is the CS‑360 Event Tracking Mobile Application. This application was initially created during the CS‑360 Mobile Architecture and Programming course. Its main purpose is to enable users to log in and manage their personal events by creating, viewing, editing, and deleting event entries. The application is built using Android Studio and utilizes a SQLite database for persistent data storage.

The app features several components, including a login interface, an event list display that employs a RecyclerView, and dialogs for adding and editing events. These components collaborate to deliver a comprehensive mobile application that showcases full-stack mobile development capabilities.

Enhancements and Skills Demonstrated

Several algorithm and data structure enhancements were implemented to improve the efficiency and organization of the application.

First, I improved the way events are retrieved from the database by modifying the query to include sorting using an ORDER BY clause. This ensures that events are displayed in chronological order based on date and time. Sorting is a fundamental algorithm that arranges data into a meaningful structure, allowing for easier searching and analysis. Sorting improves both usability and system efficiency by organizing data into a logical sequence.

Second, I improved the way data updates are handled within the RecyclerView. Previously, the application refreshed the entire dataset whenever a single event was added or removed using notifyDataSetChanged(). This approach is inefficient because it forces the system to redraw all elements. I replaced this with targeted update methods such as notifyItemInserted(), which update only the affected portion of the list. This change reduces unnecessary processing and improves performance.

Additionally, the application makes use of a dynamic list data structure (ArrayList) to store and manage events in memory. Lists provide efficient indexed access and are well suited for applications where data is frequently added and removed. The adapter pattern used with the RecyclerView further demonstrates structured data handling and efficient UI updates.

These enhancements demonstrate my understanding of algorithmic concepts such as sorting and efficient updates, as well as my ability to apply appropriate data structures to solve real-world problems.
